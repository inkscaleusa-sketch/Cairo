# Banco de Referencia — Ink Scale

## O QUE E ESTE ARQUIVO

Banco de roteiros finalizados e aprovados. Serve como referencia para o Script Agent modelar novos roteiros a partir de estruturas que ja foram validadas.

Todo roteiro finalizado DEVE ser adicionado aqui com a nomenclatura padrao.

---

## NOMENCLATURA OBRIGATORIA

Todo roteiro recebe um nome na seguinte estrutura:

**[FORMATO] > [NOME DO ROTEIRO]**

Exemplos:
- Reels > Estrategia de Conteudo em 3 Camadas
- Carrossel > 5 Sinais de Freelancer Fingindo Ser Negocio
- Caption > Agenda Vazia Nunca Mais
- Ad > Sistema que Lota Agenda em 30 Dias

O Script Agent DEVE perguntar o nome do roteiro ao usuario antes de finalizar.
